# (TTSManager)
هو كائن تحكم (Object) في لغة JavaScript، وظيفته الأساسية هي تحويل النصوص العربية والإنجليزية إلى صوت مسموع باستخدام أصوات الويندوز والمتصفح المدمجة، مع اختيار اللهجة الأفضل تلقائياً وإعطائك رابطاً لفتح إعدادات الويندوز إذا كان الصوت غير مثبت.

شرح عمل TTSManager خطوة بخطوة


 ## 1 الإعدادات والحالة (config & state)
 
يحتوي هذا القسم على الإعدادات الافتراضية للصوت مثل السرعة (rate)، حدة الصوت (pitch)، ومستوى الصوت (volume)، بالإضافة إلى رابط إعدادات الويندوز (ms-settings:speech) الذي يُستخدم في حال عدم وجود أصوات عربية على جهاز المستخدم.

 ## 2 التهيئة وطباعة الأصوات في الكونسول (init)
 
عند تحميل الملف في الصفحة، تقوم هذه الدالة بجلب جميع الأصوات المثبتة على جهاز الكمبيوتر وطباعتها في جدول منظم داخل الـ Console (console.table) حتى تتمكن كمبرمج من رؤية أسماء الأصوات ولغاتها المتاحة على الجهاز.

 ## 3 دوال الفحص وجلب الأصوات (Getters)
 
تساعدك هذه الدوال لاحقاً إذا أردت عمل قائمة منسدلة (Dropdown) للمستخدم أو فحص جهازه:
• getAvailableVoices(): تجلب كل الأصوات المتاحة في المتصفح.
• getArabicVoices(): تفلتر الأصوات وتُرجع الأصوات العربية فقط.
• getEnglishVoices(): تُرجع الأصوات الإنجليزية فقط.
• hasArabicSupport(): تُرجع true إذا كان جهاز المستخدم يدعم اللغة العربية، أو false إذا لم يكن لديه أي صوت عربي مثبت.

4. اختيار أفضل صوت تلقائياً (selectBestVoice)

تقوم هذه الدالة بفحص النص، فإذا كان عربياً تبحث بالترتيب التالي:
1. الصوت السعودي (ar-SA): وتفضل الأصوات الطبيعية عالية الجودة (Natural) إذا كان المستخدم يفتح الموقع من متصفح Microsoft Edge.
2. الصوت المصري (ar-EG): إذا لم تجد صوتاً سعودياً، تنتقل تلقائياً للصوت المصري.
3. أي صوت عربي آخر (ar): إذا لم تجد السعودي أو المصري، تختار أي صوت عربي متاح (مثل الإماراتي أو الأردني).
4. إذا كان النص إنجليزياً: تختار أنقى صوت إنجليزي متاح (مثل أصوات Google أو Microsoft Natural).

5. دالة النطق الرئيسية (speak)

هي الدالة التي تستدعيها من تطبيقك (سواء من JavaScript أو Blazor C#)، وتعمل كالتالي:
• توقف أي صوت يعمل حالياً (this.stop()) حتى لا تتداخل الأصوات.
• تكتشف تلقائياً هل النص المكتوب عربي أم إنجليزي.
• تنطق النص وترجع لك نتيجة واضحة (Promise) تخبرك هل نجح النطق أم لا، واسم الصوت المستخدم، أو رابط ms-settings:speech إذا فشل النطق لعدم وجود حزمة لغة.

6. إيقاف الصوت (stop)

تُستخدم لإيقاف القراءة الصوتية فوراً في أي لحظة.

أمثلة عملية للاستخدام


المثال الأول: النطق التلقائي (عربي أو إنجليزي)

بمجرد تمرير النص، سيختار الكود اللهجة السعودية (أو المصرية كبديل) تلقائياً:
```javascript

TTSManager.speak("مرحباً بك في نظامنا الذكي").then(result => {
    if (result.success) {
        console.log("تم النطق بنجاح باستخدام:", result.voice);
    } else {
        console.log("فشل النطق:", result.error);
        // هنا يمكنك إظهار زر للمستخدم يفتح: result.windowsSettingsUri
    }
});


// نطق نص إنجليزي

TTSManager.speak("Welcome to our smart system.");
```

 ## المثال الثاني: التحكم في سرعة الصوت أو اختيار صوت محدد بالاسم
 
 ### يمكنك تمرير إعدادات مخصصة في المعامل الثاني للدالة:
 
 ```javascript
TTSManager.speak("أهلاً وسهلاً بكم", {
    rate: 0.9, // أبطأ قليلاً لوضوح أكثر
    pitch: 1.0,
    voiceName: "Microsoft Hamed Online (Natural) - Arabic (Saudi Arabia)" // اختيار صوت محدد بالاسم (اختياري)
});
```
المثال الثالث: فحص هل يدعم جهاز المستخدم العربية أم لا

مفيد جداً عند فتح الصفحة لإظهار تنبيه للمستخدم إذا كان جهازه يفتقد للغة العربية:
```javascript
if (!TTSManager.hasArabicSupport()) {
    console.warn("جهازك لا يحتوي على أصوات عربية! اضغط على الرابط لتثبيتها: ms-settings:speech");
}
```

 ## المثال الرابع: الاستدعاء من داخل Blazor (C#)
 
في ملف .razor الخاص بك، يمكنك استدعاء الكود وإظهار زر إعدادات الويندوز إذا لم يجد أصواتاً:
```csharp
@inject IJSRuntime JS

<button @onclick="SpeakText">تشغيل الصوت</button>

@if (showWindowsSettingsBtn)
{
    <a href="ms-settings:speech" class="btn btn-warning">
        تثبيت حزمة الصوت العربي في ويندوز
    </a>
}

@code {
    private bool showWindowsSettingsBtn = false;

    private async Task SpeakText()
    {
        var result = await JS.InvokeAsync<TTSResult>("TTSManager.speak", "السلام عليكم ورحمة الله");
        
        if (!result.Success)
        {
            showWindowsSettingsBtn = true;
        }
    }

    public class TTSResult
    {
        public bool Success { get; set; }
        public string? Voice { get; set; }
        public string? WindowsSettingsUri { get; set; }
        public string? Error { get; set; }
    }
}
```
